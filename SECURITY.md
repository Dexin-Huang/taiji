# Security Policy

## Reporting a vulnerability

Don't open a public issue. Use GitHub's private vulnerability reporting instead.

I'll acknowledge within 48 hours and respond in detail within 5 business days.

## Scope

Taiji executes `yin.py` and `yang.py` as arbitrary Python. That's by design. The runtime trusts whatever code is in those files. Don't point it at unit definitions you haven't read.
