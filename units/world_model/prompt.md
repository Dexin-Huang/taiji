# North Star

Build a system that continuously learns, adapts to, and models arbitrary
data streams — using only forward-pass computation, no gradient updates
at test time. The system must demonstrate genuine world-modeling, not
memorization or table lookup.

# Acceptance Criteria

The system must pass ALL FOUR tests below on at least 3 structurally
different stream types. Report results on each stream independently.

## Definitions

- N = 100 (window size in tokens/steps)
- Steady-state loss: mean loss over the last 3N steps of a phase
- Recovery horizon: steps after a distribution shift until loss is
  within 1.2x of the new steady-state loss
- All thresholds are measured as ratios relative to the system's own
  baseline, not absolute values
- Statistical significance: p < 0.01, one-sided paired t-test, across
  at least 5 independent runs per stream type

## Test 1: Learning

Setup: Present a novel stream the system has never seen.
Measure: Loss in windows [0, N] vs [4N, 5N].
Pass criterion: Loss decreases by >= 30%.
Failure mode: A frozen model that never updates representations.

## Test 2: Adaptation

Setup: At step T1, shift to a new distribution (the shift must cause a
loss spike of >= 50% above pre-shift steady-state — if it doesn't, the
shift is too easy and must be replaced with a harder one).
Measure: Recovery horizon R2 = steps to reach within 1.2x of new
steady-state.
Pass criterion: R2 < 5N.
Failure mode: A model that cannot update its predictions without
retraining.

## Test 3: Memory

Setup: At step T2, switch back to the original distribution.
Measure: Recovery horizon R3.
Pass criteria (BOTH required):
  (a) R3 < 0.5 * R2  (at least 2x faster recovery on revisitation)
  (b) R3 < R_naive, where R_naive is measured on the same architecture
      with memory cleared between phases
Failure mode: A sliding-window model that forgets old distributions.

## Test 4: Generalization (Transfer)

Setup: After learning distributions D1 and D2, present distribution D3
which shares latent structure with D1 (e.g., same grammar family,
different parameters) but was never directly observed.
Measure: Time to reach within 1.2x of D3 steady-state = R_transfer.
Control: Time for a fresh instance (no prior exposure) to reach the
same loss on D3 = R_fresh.
Pass criterion: R_transfer < 0.5 * R_fresh.
Failure mode: A lookup table / kNN buffer that memorizes but cannot
generalize to unseen structural variants.

## Stream Requirements

The system must be evaluated on at least these three stream types:
1. Variable-order Markov chains (order 1-5, with mid-stream order changes)
2. Streams generated by context-free grammars (with mid-stream grammar swaps)
3. Periodic time series with additive noise (with mid-stream frequency/phase shifts)

## Reporting

For each stream type, report:
- Raw loss curves (all steps, not just summaries)
- Window-averaged loss at each phase
- Recovery horizons R2, R3, R_transfer, R_fresh
- Ratios: R3/R2, R_transfer/R_fresh
- p-values for each test
- Comparison against two baselines:
  (a) Frozen model (same architecture, no adaptation mechanism)
  (b) Memoryless baseline (memory cleared between phases)
