# Goal

Build a system that continuously learns and models the world.

It runs forever on a stream of experience. It builds an internal model of
the process generating that stream. It updates that model in real time. It
predicts what comes next. It gets better the longer it runs — not from
retraining, from experience.

When the stream changes, the system notices and adapts. When something it
modeled before reappears, it remembers. It never runs out of memory. It
never slows down.

The deliverable is a working implementation that demonstrates all of this
on real data — not synthetic benchmarks. Train it. Run it. Show it learns
continuously, models the world, and scales.
