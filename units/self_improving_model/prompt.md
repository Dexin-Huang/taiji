# Goal

Build a self-improving model.

The model should become better through use, not only through offline training.
It should adapt at test time using only the information available at test time.
It should preserve useful prior competence while incorporating new information.
It should remain computationally bounded enough to be useful in real time.

Yang should search for the simplest honest mechanism that satisfies this goal.
Yin should turn only the necessary constraints into public law.
